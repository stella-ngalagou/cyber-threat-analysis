# Analyses de menaces cyber

Deux travaux d'analyse de la menace (*threat intelligence*) réalisés dans le cadre du **Mastère Spécialisé Expert Big Data** (Université de Technologie de Troyes, octobre 2026).

| Analyse | Ce qu'elle montre | Dossier |
|---|---|---|
| **Rapport d'analyse de menace : groupe ChimeraZ** | Analyse d'un vol de 7 546 documents d'identité chez une armurerie française : motivation financière de l'attaquant, déroulé de l'attaque relié aux tactiques MITRE ATT&CK, impacts (clients, victime, secteur), mesures de protection priorisées pour un RSSI | [`chimeraz/`](chimeraz/rapport_analyse_menace.md) |
| **Cartographie MITRE ATT&CK du secteur aérien** | 7 groupes ciblant l'aviation depuis au moins 2013 : plateformes visées (dont cloud et ICS), remédiations MITRE D3FEND, synthèse dans un tableau Excel | [`mitre-aviation/`](mitre-aviation/README.md) |

## Compétences mobilisées

- Analyse de menace et rédaction de rapports pour un décideur (RSSI)
- Cadres de référence **MITRE ATT&CK** et **MITRE D3FEND**
- Synthèse de données dans Excel (matrice, formules de décompte)
- Conformité : RGPD (notification CNIL, durées de conservation, analyse d'impact)
